    Informasi sistem

    Sensor IR pada ESP32 mencatat waktu tiap lewatan bandul. Data dikirim lewat WiFi ke database Supabase, lalu ditampilkan di halaman ini sehingga bisa dibuka dari mana saja dan kapan saja.

    Mode 1 menghitung periode T, percepatan gravitasi g, koreksi amplitudo, redaman, serta regresi beberapa panjang tali dan massa. Mode 2 hanya menampilkan data mentah (t masuk, t keluar) dan mengunduhnya sebagai CSV.

    Merekam dilakukan pada alat: ayunkan bandul, data muncul otomatis. Tekan tombol BOOT di ESP32 untuk memulai sesi baru.

    Cara memakai alat dan halaman ini

    Merekam data (di alat)

    1. Nyalakan ESP32 dan tunggu LED biru menyala terus (WiFi tersambung).
    2. Ayunkan bandul. Setiap lewatan terkirim otomatis, muncul di halaman ini dalam ±3 detik dengan label LIVE.
    3. Untuk percobaan baru (mis. panjang tali berbeda), tekan tombol BOOT di ESP32 lalu ayunkan lagi. Sesi baru juga dibuat otomatis bila bandul diam lebih dari 20 detik.

    Mode 1 — analisis

    1. Pilih sesi, isi L (cm), w (mm), dan massa. Hasil T, g, g koreksi, redaman langsung dihitung. Tekan Simpan parameter agar tersimpan untuk semua orang.
    2. Tekan Tambah ke Tabel Percobaan untuk tiap panjang tali yang berbeda (minimal 3), lalu lihat regresi T² terhadap L di tab Tabel Percobaan.
    3. Variasikan massa beban (minimal 3) untuk melihat tab Massa Beban.

    Mode 2 — data mentah

    Menampilkan t masuk dan t keluar tiap lewatan dan mengunduhnya sebagai CSV. File CSV ini berformat sama dengan aplikasi desktop, sehingga bisa dibuka juga di sana.
